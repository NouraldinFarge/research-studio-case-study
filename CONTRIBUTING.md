# Contributing

This is a source-free portfolio case study. Focused pull requests for corrections and documentation clarifications are welcome; implementation contributions cannot be accepted here.

Do not submit private source, binaries, catalog data, credentials, browser-session artifacts, proprietary screenshots, or material without redistribution rights. Examples must be clearly fabricated, and visuals must be original or carry reviewed redistribution rights. Keep any pull request limited to supportable documentation changes. Use private vulnerability reporting—not a pull request—for security or privacy concerns.

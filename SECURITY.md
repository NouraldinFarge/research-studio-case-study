# Security policy

This repository contains documentation only and distributes no application source, binaries, private catalogs, or authentication artifacts.

If the case study nevertheless reveals a security or privacy concern, use [GitHub private vulnerability reporting](https://github.com/NouraldinFarge/research-studio-case-study/security/advisories/new). Do not disclose private source, credentials, catalog records, browser-session material, or identifying data in a public issue.

Full local diagnostic reports are private evidence. Do not attach them to an issue, discussion, pull request, or advisory. Reproduce only the minimum sanitized facts needed to report a concern.

The documented product treats model output, database inputs, browser content, and exported data as untrusted. Human approval, read-only source access, working copies, schema validation, and redaction boundaries remain deliberate parts of the design.

The documentation workflow rejects common application, database, archive, credential, and browser-capture file types and scans text for local project paths and credential-header patterns.

# Documentation roadmap

## Near term

- Keep the architecture, trust boundaries, and verification claims aligned with the private implementation.
- Add only redacted or synthetic visual evidence with confirmed redistribution rights.
- Resolve the standalone implementation license and third-party-notice process.

## Release boundary

Source and binaries remain private until redistribution rights are reviewed and documented. A public release is not a near-term commitment and will not be created solely for portfolio appearance.
